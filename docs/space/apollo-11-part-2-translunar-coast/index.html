Apollo 11, Part 2: Translunar Coast and Lunar Orbit

Three days of falling towards the Moon, one correction, and the six-minute burn behind the far side that captured Columbia and Eagle

A reconstruction of Apollo 11 from the translunar coast to the first day in lunar orbit, anchored on NASA’s documented states and burns. Covers tracking, the midcourse correction, the Moon’s sphere of influence, loss of signal behind the Moon, lunar orbit insertion, and the mascons that pulled the orbit out of shape.

This is the second of four posts that rebuild the flight of Apollo 11 from the numbers NASA published in 1969 and 1970.

  1. Launch to translunar injection: the ascent, the parking orbit, and the burn that leaves Earth.
  2. Translunar coast and lunar orbit (this post): three days of coasting, one midcourse correction, and the two burns that put Columbia and Eagle into orbit around the Moon.
  3. Descent and landing: Eagle separates from Columbia and flies the powered descent to Tranquility Base.
  4. Rendezvous, return and entry: ascent, rendezvous with Columbia, the burn home, and splashdown.

Part 1 left the spacecraft at 2 hours 50 minutes, moving away from Earth at 10.8 km/s. This part follows it for the next four days, to 100 hours, when Neil Armstrong and Buzz Aldrin are about to undock Eagle. Along the way it covers how the spacecraft was tracked, why one small burn on day two mattered so much, where the Moon’s gravity takes over from Earth’s, why every burn at the Moon was made out of radio contact, and why the orbit around the Moon would not stay the shape it was put in.

A correction to Part 1

Building this part turned up something missing from Part 1. About two hours after TLI, once Eagle had been pulled clear of the spent S-IVB stage, the crew fired the service propulsion system (SPS) engine for 2.9 seconds. This “evasive” burn of 19.7 ft/s moved Columbia and Eagle safely away from the stage, which was about to vent its leftover propellant to send itself past the Moon. Part 1’s free-return test did not include that burn, so its uncorrected path was off. Part 1 has been updated: with the evasive burn included, the reconstruction stays within 3 n mi and 4 ft/s of every documented state up to 4 hours 40 minutes.

How this part is built

As in Part 1, the reconstruction works from anchors, states documented in the 1969 tables, and fills the gaps between them with a force model. Two things are new.

  • The Moon’s own shape. Near the Moon, the model adds the two largest terms of the Moon’s gravity field beyond a simple sphere: its flattening (\(J_2\)) and its elongation towards Earth (\(C_{22}\)). Positions on the Moon use the IAU’s model of the Moon’s orientation, so the ground track can be drawn in lunar latitude and longitude.
  • Burns that last minutes. Lunar orbit insertion took almost six minutes. The engine is modelled as a constant-thrust rocket with an exhaust velocity of 3.10 km/s, steered in the local-horizontal frame that the crew’s maneuver PADs use. The steering is solved for, by least squares, so that the trajectory meets the documented states at ignition and cutoff.

tabAt = (rows, t, n = 3) => {
  const ts = rows._t ?? (rows._t = rows.map(d => d[0]));
  const i = Math.max(0, Math.min(rows.length - 2, d3.bisectRight(ts, t) - 1));
  const a = rows[i], b = rows[i + 1], f = (t - a[0]) / (b[0] - a[0]);
  return d3.range(1, n + 1).map(j => a[j] + f * (b[j] - a[j]));
}
vec = ({
  sub: (a, b) => a.map((x, i) => x - b[i]),
  dot: (a, b) => a[0] * b[0] + a[1] * b[1] + a[2] * b[2],
  cross: (a, b) => [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]],
  norm: a => Math.hypot(a[0], a[1], a[2]),
  unit: a => { const n = Math.hypot(a[0], a[1], a[2]); return a.map(x => x / n); },
  scale: (a, k) => a.map(x => x * k)
})
rowAt = t => {
  const i = Math.max(0, Math.min(track.length - 2, d3.bisectRight(times, t) - 1));
  const a = track[i], b = track[i + 1], f = Math.max(0, Math.min(1, (t - a[0]) / (b[0] - a[0])));
  const r = a.map((x, j) => x + f * (b[j] - x));
  if (Math.abs(b[12] - a[12]) > 180) {           // selenographic longitude wraps
    const lb = b[12] + (b[12] < a[12] ? 360 : -360);
    r[12] = a[12] + f * (lb - a[12]);
    if (r[12] > 180) r[12] -= 360; if (r[12] < -180) r[12] += 360;
  }
  r.i = i; r.src = f < 0.02 ? a[13] : f > 0.98 ? b[13] : Math.max(a[13], b[13]) || 1;
  return r;
}
// Earth visible from the spacecraft? Signed clearance (km) of the line to Earth's centre past the lunar limb.
earthClear = r => {
  const s = [r[1], r[2], r[3]], w = [-r[4], -r[5], -r[6]];
  const u = vec.unit(vec.scale(s, -1)), along = vec.dot(w, u);
  if (along < 0) return 1e4;
  return vec.norm(vec.sub(w, vec.scale(u, along))) - RM;
}
losTimes = {
  const out = [];
  let prev = null;
  for (const d of track) {
    if (d[0] < 270000) continue;
    const c = earthClear(d);
    if (prev && (prev[1] > 0) !== (c > 0)) {
      const tc = prev[0] + (d[0] - prev[0]) * prev[1] / (prev[1] - c);
      out.push([tc, prev[1] > 0 ? "LOS" : "AOS"]);
    }
    prev = [d[0], c];
  }
  return out;
}
state = {
  const r = rowAt(T), s = {};
  data.meta.columns.forEach((c, j) => { s[c] = r[j]; });
  s.get = T; s.i = r.i; s.src = r.src;
  s.rE = Math.hypot(r[1], r[2], r[3]);
  s.rM = Math.hypot(r[4], r[5], r[6]);
  s.clear = earthClear(r);
  s.phase = phases.filter(p => p[0] <= T).at(-1)[1];
  // Moon-relative osculating orbit from a centred difference.
  const a = rowAt(T - 5), b = rowAt(T + 5);
  const rv = [r[4], r[5], r[6]], vv = [0, 1, 2].map(j => (b[4 + j] - a[4 + j]) / 10);
  const mu = 4902.80, rn = vec.norm(rv), vn = vec.norm(vv);
  const sma = 1 / (2 / rn - vn * vn / mu), h = vec.cross(rv, vv);
  const ev = vec.sub(vec.scale(vec.cross(vv, h), 1 / mu), vec.scale(rv, 1 / rn)), e = vec.norm(ev);
  s.orb = {apo: sma > 0 ? sma * (1 + e) - RM : Infinity, peri: sma * (1 - e) - RM, e, period: sma > 0 ? 2 * Math.PI * Math.sqrt(sma ** 3 / mu) : NaN};
  s.rev = T < burnsAt.l1 ? 0 : 1 + losTimes.filter(([t, k]) => k === "LOS" && t > burnsAt.l1c && t <= T).length;
  return s;
}

frames = {

The rest of the post explains what is going on, roughly in the order it happened.

Tracking a spacecraft from Earth

For the three days between TLI and the Moon, nobody aboard was steering. Columbia and Eagle were falling, along a path set by the TLI burn and by the gravity of Earth, the Moon and the Sun. Mission Control knew where they were by tracking them: the 85-foot dishes of the Manned Space Flight Network in Goldstone, Madrid and Honeysuckle Creek measured the range to the spacecraft from the round-trip time of a radio signal, and the range rate from its Doppler shift. Fitting a trajectory to hours of those measurements gave a state vector good to a fraction of a mile.

The flight controllers shared the results. Every so often the Public Affairs Officer (PAO) read out the spacecraft’s distance and speed to the press. Those calls are in the transcript, and they make a good test of the reconstruction, because none of them was used to build it. The distances turn out to be heights above the surface, not distances from the centre, and once the Moon is close they switch to being measured from the Moon.

The one midcourse correction

The flight plan allowed for four midcourse corrections on the way out. Only one was needed. At 26 hours 44 minutes 58 seconds the SPS fired for 3.13 seconds and changed the velocity by 20.9 ft/s, about 6 m/s, at a moment when the spacecraft was moving at 5,025 ft/s relative to Earth.

Small as it was, it mattered. By 26 hours the reconstruction, propagated from TLI, has drifted 84 n mi from where NASA’s tables put the spacecraft. That is not an error in the physics; a trajectory to the Moon is so sensitive that tiny differences at the start grow into large ones. So at MCC-2 the reconstruction is re-anchored on the documented state and starts again.

checks("coast", c => c[1].startsWith("MCC") || c[1].startsWith("Re-anchoring"))

The burn itself is known from the maneuver PAD that Bruce McCandless, the CapCom, read up to the crew an hour before: the velocity change in the local-vertical frame, mostly downwards, towards Earth, and partly forwards. Applying the PAD’s direction scaled to the achieved 20.9 ft/s does not bring the spacecraft to the right place:

checks("mcc")

Applied as recorded, the burn would bring the spacecraft past the Moon at 177 n mi rather than the documented 86.7 n mi; with no burn at all, it would pass at 326 n mi. The fitted burn that does arrive at the right height, at the right speed and with loss of signal at the right moment is 19.0 ft/s, about 2 ft/s smaller than the documented one and in a slightly different direction.

That 2 ft/s is a measure of how sensitive the trajectory is, more than of anything wrong with the burn. At this point each foot per second moves the arrival by tens of nautical miles. The documented state used as the anchor is given to the nearest tenth of a nautical mile in height and the nearest hundredth of a degree in direction, and a hundredth of a degree in the direction of travel, 200,000 km from Earth, is already a few tens of kilometres. The fit absorbs that rounding. What the comparison does show is why Apollo did not rely on a single correction: the navigation teams tracked the result of each burn and planned the next, and on Apollo 11 the other scheduled corrections were not needed.

Where the Moon takes over

Halfway to the Moon by distance is not halfway by gravity. The Moon is 81 times less massive than Earth, so the point where their pulls balance lies about 90% of the way there. For working out trajectories, though, the balance point is not the most useful boundary. What matters is where it becomes more accurate to treat the Moon as the main attractor and Earth as a disturbance than the other way round. Laplace worked out the radius of that sphere of influence:

\[ r_\text{SOI} \approx a\left(\frac{m}{M}\right)^{2/5}, \]

where \(a\) is the Earth–Moon distance and \(m/M\) the mass ratio. For the Moon that is about 66,000 km. Inside it, the motion is well described by a two-body orbit around the Moon; outside, by one around Earth. Joining the two at the boundary is the method of patched conics, which Apollo’s planners used for first estimates before refining with numerical integration, as this reconstruction does throughout.

NASA logged the crossing at 61 hours 39 minutes 55 seconds:

checks("soi")

The documented crossing, 34,765 n mi from the Moon’s centre, sits a little inside the Laplace radius for that moment, 36,886 n mi. The formula is an approximation, and NASA’s software used its own definition of the boundary. The speeds at the crossing are the clearer story. Relative to Earth, the spacecraft had slowed to 2,990 ft/s. Relative to the Moon it was moving faster, 3,775 ft/s, because the Moon itself travels at about 3,350 ft/s in its orbit, across the spacecraft’s path. From here, the Moon accelerated it all the way in.

Behind the Moon

Every burn at the Moon was made out of radio contact. That was not chosen; it is geometry. To slow down into lunar orbit, the spacecraft has to burn at its closest point to the Moon, and a free-return trajectory passes closest behind the Moon, as seen from Earth. So the critical burn happened with the Moon between the crew and Mission Control, and the controllers learned whether it had worked only when the signal came back.

The loss and acquisition of signal (LOS and AOS) times are well documented, from PADs read to the crew and from PAO announcements. In the model they come from pure geometry: the moment the line from the spacecraft to Earth’s centre grazes the edge of the Moon.

At 75 hours 49 minutes 50 seconds, 86.7 n mi above the far side, Columbia’s engine fired for 357.5 seconds, nearly six minutes, to slow the stack by 2,917 ft/s.

Arriving fast

The spacecraft arrived at 8,250 ft/s relative to the Moon. Escape speed at that height is

\[ v_\text{esc} = \sqrt{\frac{2\mu_\text{Moon}}{r}} = \sqrt{\frac{2 \times 4902.8}{1898.7}}\ \text{km/s} \approx 2.27\ \text{km/s} = 7{,}456\ \text{ft/s}, \]

so the spacecraft was on a hyperbola: left alone, it would have whipped round the Moon and left with about 1.1 km/s to spare, which is what the free-return design intended. To be captured, it had to shed at least 800 ft/s. To reach the planned orbit, it shed 2,917.

As with TLI, the Oberth effect favours burning where the spacecraft is moving fastest, at the closest point to the Moon. Changing speed by \(\Delta v\) there changes the orbital energy by \(v\,\Delta v\), so the same braking does the most good.

A six-minute burn

Six minutes is long. During the burn the spacecraft travelled about 750 km, more than 20° of the way round the Moon. A burn that long cannot be treated as an instant change of velocity, so it is modelled as a finite, constant-thrust burn. The fit solves for the steering that joins the documented state at ignition to the documented cutoff conditions:

checks("arrival")
checks("loi1")

Two features of the fitted steering stand out. First, the thrust at ignition points 15.7° away from the PAD direction. The PAD’s velocity change is an impulsive equivalent: the single kick at one instant that would have the same result. A real burn that sweeps through 20° of arc has to start pointing off that direction and end pointing off it the other way. Second, the fit settles on a steady pitch of 0.075° per second relative to the local horizontal. That is almost exactly the rate at which the local horizontal itself turns as the spacecraft moves round the Moon, about \(v/r = 2.5/1900\) radians per second, or 0.076° per second. In other words the thrust stayed close to fixed in space, as the guidance would hold it, while the Moon’s surface turned beneath.

The burn also changed the plane of the orbit. The PAD had a sideways component of 394 ft/s, which in the reconstruction turns the plane by about 5°. The approach path had been chosen for a safe free return; the orbit had to pass over the landing site two days later.

The height keeps falling through the burn: the spacecraft reaches its closest point to the Moon during the braking, not before it. The result was an orbit of about 170 by 60 n mi, with a period of 2 hours 8.6 minutes.

LOI-2

Two revolutions later, at 80 hours 11 minutes 36 seconds, a second burn of 16.9 seconds lowered the far point of the orbit. This one was made at the low point, behind the Moon again, and was nearly impulsive, so it is easier to fit.

checks("loi2")

The orbit after LOI-2 was 66.1 by 54.5 n mi, not circular. That was deliberate, and the last row of the table shows the reconstruction agreeing with its purpose: two and a half days later, at 102 hours 45 minutes, the plane of the orbit passes within 0.03 n mi of Tranquility Base. The orbit’s shape was chosen so that the Moon’s gravity would pull it round to nearly circular, about 60 n mi, by the time Eagle landed and Columbia had to pass overhead. That prediction depended on the Moon’s uneven gravity.

Mascons

In 1968, Paul Muller and William Sjogren at JPL analysed the tracking of the Lunar Orbiter spacecraft and found that the Moon’s gravity was lumpy. Under the large circular maria, the dark plains on the near side, there are concentrations of mass, mascons, that pull orbiting spacecraft down as they pass over and speed them up. Their effect on a low orbit is large: over a day they can change its height by miles.

The force model in this reconstruction has only the two largest, smoothest terms of the lunar gravity field. Those cannot reproduce the mascons, and the comparison shows it:

The view from lunar orbit

Apollo 11’s orbit was retrograde: it went round the Moon from east to west, at an inclination of about 1° to the lunar equator. Seen from Earth the spacecraft crossed the near side from right to left, passed over the eastern maria, Smythii, Fecunditatis and Tranquillitatis, and disappeared behind the western limb into the radio shadow. Watch the Moon panel through a revolution to see the track cross the landing site.

On the second revolution the crew pointed a television camera out of the window and flew the approach to the landing site for viewers on Earth, calling out the landmarks Eagle would use: the crater Secchi, Mount Marilyn near the point where the descent engine would light, Boot Hill, Duke Island, and the winding rilles Sidewinder and Diamondback. That broadcast began at 78 hours 24 minutes; jump to TV from orbit to follow it on the track.

If the engine had not fired

The free-return trajectory was the safety net for LOI. If the SPS had failed to fire, Apollo 11 would have swung round the Moon and come back. The reconstruction can follow that path too: take the arrival state at LOI-1 ignition and propagate with no burn. Select Rotating with the Moon above to see it as the purple dashed curve.

checks("freereturn")

The spacecraft would have reached Earth’s atmosphere at about 145 hours, six days after launch. The yellow dashed curve is the path with no midcourse correction, passing the Moon higher and coming back on a different line. In the frame that turns with the Moon, both form the figure-of-eight that free-return trajectories are known for.

Method and sources

For how the coordinate frames, views, synchronisation and data sources fit together across the series, see the explainer Frames of Reference in the Apollo 11 Reconstruction.

The reconstruction is written in Python with numpy and is driven from a single file of documented anchors, each tagged with its source. The force model is Earth’s central gravity plus J2, the Moon and the Sun as third bodies from JPL’s DE421 ephemeris, and, within 20,000 km of the Moon, the Moon’s J2 and C22 terms (\(J_2 = 2.033\times10^{-4}\), \(C_{22} = 2.238\times10^{-5}\)), oriented by the IAU 2009 lunar rotation model. Everything is expressed in the mean equator and equinox of 16 July 1969, the frame of the Apollo tables. The integrator is Dormand–Prince 5(4) with a relative tolerance of 10⁻¹¹. Heights above the Moon are measured from a sphere of radius 1,738.09 km, the reference radius of the 1969 tables. Burns are fitted with a damped least-squares (Levenberg–Marquardt) solver, with the PAD values as weak priors.

The pipeline is:

  1. From the documented TLI state, coast with the documented evasive burn to midcourse correction 2.
  2. Re-anchor on the documented state at MCC-2 ignition and fit the 3-second burn so the trajectory arrives with the documented height and speed at LOI-1 ignition, the documented loss of signal, and the documented closest approach.
  3. Fit LOI-1 and LOI-2 as finite burns to the documented ignition and cutoff conditions, with the landing site’s distance from the orbit plane at landing as one more target.
  4. Propagate to 100 hours with no further changes.

Every other number in the post, including the PAO distances and speeds, the sphere-of-influence crossing, the loss and acquisition of signal times after LOI-1, and the orbits from 80 to 100 hours, was not used in the fit and serves as a check.

Documented values come from:

  • R. W. Orloff and S. Garber, Apollo by the Numbers, NASA SP-2000-4029, Apollo 11 translunar and lunar orbit tables, via the Apollo Flight Journal edition.
  • TRW, Apollo Mission 11 Trajectory Reconstruction and Postflight Analysis (1970).
  • The Apollo 11 Flight Journal, for the maneuver PADs, the LOS and AOS times, and the narrative of the coast and lunar orbit.
  • NASA’s Apollo 11 Technical Air-to-Ground Voice Transcription and Onboard Voice Transcription, via Spacelog, for the transcript and the PAO calls.
  • NASA’s mission audio highlights reels for Day 2, Day 3 and Day 4 at the Internet Archive. Each reel is an edited selection; segments are pinned to mission time by matching the reel’s captions to the transcript, and are accurate to a few seconds.
  • P. M. Muller and W. L. Sjogren, “Mascons: lunar mass concentrations”, Science 161 (1968), 680–684.
