In 2017 eight researchers at Google published Attention Is All You Need. It proposed a model for translation built from one repeated operation, attention, with no recurrence and no convolution, and it trained faster and translated better than anything before it. Almost every large language model since is a transformer, most of them a stripped-down version of the one in that paper.

This is the first of three posts. This one takes the architecture apart operation by operation: what every tensor is, what shape it has, what each equation computes and why it was chosen. Part 2 runs a real trained transformer, GPT-2, and looks inside it. Part 3 covers what has changed since 2017. The two embedding posts cover the first and last steps, turning text into vectors and back, in more depth.

Notation

Everything here uses the row-vector convention, the one in the original paper and in essentially all code: a token’s vector is a row, and a linear layer is \(\mathbf x W + \mathbf b\) with \(W \in \mathbb R^{d_{\text{in}}\times d_{\text{out}}}\). Stacking the \(T\) token vectors of a sequence as the rows of a matrix gives \(X \in \mathbb R^{T\times d}\), and a layer applied to every token at once is just \(XW\). With a batch of \(B\) sequences, the activations are a three-way tensor of shape \((B, T, d)\).

Symbol Meaning 2017 base model GPT-2 small
\(B\) sequences in a batch
\(T\) tokens in a sequence (context length) up to 1,024
\(d\) model width, \(d_{\text{model}}\) 512 768
\(h\) attention heads 8 12
\(d_h = d/h\) width of one head (\(d_k = d_v\) in the paper) 64 64
\(d_{\text{ff}}\) feed-forward width 2,048 3,072
\(N\) layers 6 + 6 12
\(V\) vocabulary 37,000 50,257

Tensor contractions are also given in Einstein summation notation, as NumPy’s and PyTorch’s einsum write them: "btd,de->bte" means \(Y_{bte} = \sum_d X_{btd}W_{de}\), indices repeated on the left and missing on the right are summed.

Embedding and position

The token ids are looked up in the embedding table \(E \in \mathbb R^{V\times d}\), giving \(X \in \mathbb R^{T\times d}\); Part 1 of the embeddings series covers how that table is learned and what its geometry means. The 2017 model multiplies the result by \(\sqrt d\). The paper does not say why; the usual reading is that its embedding table is shared with the output layer and so has small entries, while the sinusoidal position signal added next has entries of size 1, and the scaling stops position from drowning out the token.

Attention, as the next section shows, treats its input as a set: permute the rows of \(X\) and the output rows are permuted the same way. Order has to be put into the vectors themselves. The 2017 model adds fixed sinusoids, \(P_{p,2i} = \sin(p/10000^{2i/d})\) and \(P_{p,2i+1} = \cos(p/10000^{2i/d})\), chosen so that a shift by \(k\) positions is a fixed rotation of each pair of coordinates; GPT-2 learns a \(1{,}024\times d\) table instead, and most current models rotate the queries and keys (RoPE). The derivations are in the embeddings post; Part 3 covers what came after.

Attention

A soft lookup table

A dictionary maps keys to values: present a query, find the key that matches, return its value. Attention makes every step soft. Each token emits three vectors: a query (what it is looking for), a key (what it offers to be found by) and a value (what it passes on if found). Token \(i\) scores every token \(j\) by the dot product of its query with their key, turns the scores into weights with a softmax, and receives the weighted average of the values:

\[ \mathbf z_i = \sum_{j} \alpha_{ij}\,\mathbf v_j, \qquad \alpha_{ij} = \frac{\exp(\mathbf q_i\cdot\mathbf k_j/\sqrt{d_h})}{\sum_{j'}\exp(\mathbf q_i\cdot\mathbf k_{j'}/\sqrt{d_h})}. \]

In matrix form, with \(Q = XW^Q\), \(K = XW^K\), \(V = XW^V\),

\[ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_h}}\right)V, \]

the softmax taken along each row. Statisticians will recognise the form: it is Nadaraya–Watson kernel regression, an estimate at a query point formed as a kernel-weighted average of observed values, with the exponential of a dot product as the kernel. What makes it powerful is that the queries, keys and values are all learned projections of the same input, so the model learns what to look for as well as what to return.

The important property is that the weights depend on the content. A convolution mixes neighbours with fixed weights; attention computes new weights for every input. And every token can reach every other in one step, where a recurrent network has to pass information along the sequence one position at a time.

Worked example

Five tokens, \(d = 4\), one head: the panel computes each matrix with random but fixed weights. The colours run from blue (negative) through white to red (positive); the attention matrix \(A\) runs from white to dark. worked = {
  const toks = ["the", "cat", "sat", "on", "mat"], T = 5, d = 4;
  let s = wk.seed * 7919 + 13; const rnd = () => { s = (s * 16807) % 2147483647; return s / 2147483647; };
  const g = () => Math.sqrt(-2 * Math.log(rnd() + 1e-12)) * Math.cos(2 * Math.PI * rnd());
  const M = (r, c, sd = 1) => Array.from({length: r}, () => Array.from({length: c}, () => g() * sd));
  const mul = (A, B) => A.map(r => B[0].map((_, j) => r.reduce((a, x, k) => a + x * B[k][j], 0)));
  const X = M(T, d), WQ = M(d, d, 0.45), WK = M(d, d, 0.45), WV = M(d, d, 0.8);
  const Q = mul(X, WQ), K = mul(X, WK), Vv = mul(X, WV);
  const KT = K[0].map((_, j) => K.map(r => r[j]));
  const S = mul(Q, KT).map(r => r.map(x => x * wk.temp / (wk.scale ? Math.sqrt(d) : 1)));
  const A = S.map((r, i) => { const m = r.map((x, j) => (wk.mask && j > i) ? -Infinity : x); const mx = Math.max(...m);
    const e = m.map(x => Math.exp(x - mx)); const z = e.reduce((a, b) => a + b, 0); return e.map(x => x / z); });
  const Z = mul(A, Vv);
  return {toks, X, Q, K, V: Vv, S, A, Z};
}

Why divide by \(\sqrt{d_h}\)

Suppose the components of \(\mathbf q\) and \(\mathbf k\) are independent with mean 0 and variance 1, roughly what initialisation and normalisation produce. Then

\[ \mathbb E[\mathbf q\cdot\mathbf k] = 0, \qquad \operatorname{Var}(\mathbf q\cdot\mathbf k) = \sum_{i=1}^{d_h}\operatorname{Var}(q_i k_i) = \sum_{i=1}^{d_h}\mathbb E[q_i^2]\,\mathbb E[k_i^2] = d_h. \]

The scores grow like \(\sqrt{d_h}\). With \(d_h = 64\) their standard deviation is 8, and a softmax over numbers that spread puts almost all its weight on the largest. That matters for learning, through the softmax’s derivative. Writing \(\mathbf p = \operatorname{softmax}(\mathbf s)\),

\[ \frac{\partial p_i}{\partial s_j} = p_i\,([i=j] - p_j), \qquad J = \operatorname{diag}(\mathbf p) - \mathbf p\mathbf p^\top. \]

When one \(p_i\) is close to 1 and the rest close to 0, every entry of \(J\) is close to zero, and almost no gradient flows back to the queries and keys: the model cannot learn to change where it looks. Dividing by \(\sqrt{d_h}\) restores unit variance whatever the head width. The chart samples random unit-variance queries and keys and shows the largest attention weight in a row of 64 keys, averaged over many rows, with and without the scaling:

Unscaled, the largest weight in a typical row is about 0.8 at \(d_h = 64\) and close to 1 beyond: before any learning has happened, attention has all but collapsed onto one key. Scaled, it stays at about 0.1 at every width, and gradients can flow.

Many heads

One attention pattern per layer is restrictive: a token may need to look at the previous word for grammar and at a name twenty tokens back for meaning. Multi-head attention runs \(h\) attentions in parallel, each on its own \(d_h = d/h\)-dimensional projection, and joins the results:

\[ \operatorname{MHA}(X) = [\,Z_1\;Z_2\;\cdots\;Z_h\,]\,W^O, \qquad Z_j = \operatorname{softmax}\!\left(\frac{XW^Q_j (XW^K_j)^\top}{\sqrt{d_h}}\right) XW^V_j. \]

In code nothing is looped. The \(d\times d\) projections compute all heads at once, and the heads are separated by a reshape: the last axis of \(Q \in \mathbb R^{B\times T\times d}\) is cut into \(h\) blocks of \(d_h\), giving \((B,T,h,d_h)\), and transposed to \((B,h,T,d_h)\) so that the head index behaves like another batch index. The 3D view shows that split for a toy \(T = 6\), \(d = 12\), \(h = 3\):

Two facts about heads are worth stating precisely. First, each head’s scores are a bilinear form \(\mathbf x_i W^Q_j (W^K_j)^\top \mathbf x_k^\top\) whose matrix \(W^Q_j (W^K_j)^\top \in \mathbb R^{d\times d}\) has rank at most \(d_h\): each head can only compare tokens along a \(d_h\)-dimensional subspace. More heads mean more, narrower comparisons for the same cost. Second, splitting \(W^O\) into \(h\) blocks of \(d_h\) rows shows that concatenating and projecting is the same as projecting each head separately and adding:

\[ [\,Z_1\;\cdots\;Z_h\,]\,W^O = \sum_{j=1}^h Z_j\,W^O_j, \]

so each head writes its own contribution into the residual stream. That additive view is the basis of the interpretability work in Part 2.

Masks and cross-attention

A mask is added to the scores before the softmax, with \(-\infty\) where attention is forbidden, so those weights become exactly zero. The causal mask forbids attending to later positions. It is what lets a decoder be trained on a whole sequence at once: position \(t\) predicts token \(t+1\) having seen only tokens \(1..t\), so one forward pass yields \(T\) training examples without any leak of the answers. A padding mask stops real tokens from attending to the filler added to make sequences in a batch the same length.

The 2017 model translates, so it has two stacks. The encoder reads the source sentence with unmasked self-attention, every word seeing every other. The decoder generates the translation with masked self-attention and, in each layer, a third sublayer of cross-attention: its queries come from the decoder, its keys and values from the encoder’s final output. For a source of \(T_s\) tokens and a target of \(T_t\), the score matrix is \(T_t \times T_s\): each target position looks across the whole source sentence. This is the attention of Dzmitry Bahdanau, Kyunghyun Cho and Yoshua Bengio’s 2014 translation model, which the transformer kept while removing the recurrent network around it.

GPT and most later language models dropped the encoder. A decoder-only model treats the prompt and the answer as one sequence and uses only masked self-attention; BERT kept only the encoder, for reading. Switch the tracer between the two to compare.

The feed-forward layer

After attention mixes information between positions, each position is processed on its own by a two-layer network:

\[ F(X) = \phi(XW_1 + \mathbf b_1)\,W_2 + \mathbf b_2, \qquad W_1 \in \mathbb R^{d\times d_{\text{ff}}},\; W_2\in\mathbb R^{d_{\text{ff}}\times d}, \]

with \(d_{\text{ff}} = 4d\) and \(\phi\) the ReLU in 2017 and GELU in GPT-2. It holds two-thirds of each layer’s parameters: \(2d\,d_{\text{ff}} = 8d^2\) against attention’s \(4d^2\). Mor Geva and colleagues (2021) gave it a reading that has stuck: the rows of \(W_1\) are keys that detect patterns in the token’s vector, and the matching rows of \(W_2\) are values added to the residual stream when they fire, so the layer works as a large key–value memory. Much of what a model knows about the world appears to be stored here.

Residuals and normalisation

Every sublayer is wrapped in a residual connection (Kaiming He and colleagues, 2015) and a layer normalisation (Jimmy Ba, Jamie Kiros and Geoffrey Hinton, 2016). Layer normalisation rescales each token’s vector across its \(d\) features:

\[ \operatorname{LN}(\mathbf x) = \boldsymbol\gamma \odot \frac{\mathbf x - \mu(\mathbf x)}{\sqrt{\sigma^2(\mathbf x) + \epsilon}} + \boldsymbol\beta, \qquad \mu = \frac1d\sum_i x_i,\;\; \sigma^2 = \frac1d\sum_i (x_i - \mu)^2. \]

The 2017 paper placed it after the residual addition, Post-LN: \(X \leftarrow \operatorname{LN}(X + F(X))\). GPT-2 moved it inside the branch, Pre-LN: \(X \leftarrow X + F(\operatorname{LN}(X))\), with a final normalisation before the output. The difference shows in the gradient. With Pre-LN, unrolling the layers gives

\[ X_L = X_0 + \sum_{l=0}^{L-1} F_l\big(\operatorname{LN}(X_l)\big), \qquad \frac{\partial X_L}{\partial X_l} = I + \sum_{m=l}^{L-1}\frac{\partial F_m(\operatorname{LN}(X_m))}{\partial X_l}: \]

there is an identity path from the loss to every layer, and gradients reach the early layers undiminished. With Post-LN the identity path passes through a normalisation at every layer, and Ruibin Xiong and colleagues (2020) showed that the gradients near the output are then large at initialisation, which is why the 2017 model needed a learning-rate warm-up to train at all. Pre-LN trains without one, and nearly every large model since uses it.

This also gives the cleanest picture of what a transformer is. The vector for each position is a residual stream running from the embedding at the bottom to the unembedding at the top. Every attention head and every feed-forward layer reads from the stream (through a normalisation) and adds its result back. Nothing overwrites; everything accumulates.

The output and the loss

After the last layer, each position’s vector is multiplied by the unembedding matrix to give a score, a logit, for every token in the vocabulary, \(L = XE^\top\) when the weights are tied as in GPT-2 and the 2017 model; a softmax turns the logits into a distribution over the next token. Training minimises the cross-entropy, the average of \(-\log p_{t,y_t}\) over all positions. Its gradient with respect to the logits is \(\mathbf p - \mathbf e_{y}\), derived in the embeddings post.

The 2017 model softened the targets with label smoothing: instead of probability 1 on the true token, the target puts \(1-\varepsilon\) there and spreads \(\varepsilon = 0.1\) evenly over the vocabulary,

\[ \mathcal L_{\text{ls}} = -(1-\varepsilon)\log p_y - \frac{\varepsilon}{V}\sum_{v}\log p_v. \]

The model can never reach zero loss and is discouraged from becoming over-confident. The paper reports that this made perplexity worse but translation accuracy (BLEU) better.

Training the 2017 model

The base model was trained on about 4.5 million English–German sentence pairs, with batches of about 25,000 source and 25,000 target tokens, for 100,000 steps: twelve hours on eight NVIDIA P100 GPUs. The big model took 300,000 steps, three and a half days. Both used Adam with \(\beta_1 = 0.9\), \(\beta_2 = 0.98\), \(\epsilon = 10^{-9}\), dropout of 0.1 on each sublayer’s output and on the embeddings, and a learning rate that rose linearly for 4,000 steps and then fell as the inverse square root of the step:

\[ \eta(s) = d^{-1/2}\,\min\!\left(s^{-1/2},\; s\cdot s_{\text{warm}}^{-3/2}\right). \]

Counting parameters and arithmetic

Ignoring biases and normalisation, a decoder layer has \(4d^2\) attention parameters (\(W^Q, W^K, W^V, W^O\)) and \(2d\,d_{\text{ff}} = 8d^2\) feed-forward parameters: \(12d^2\) per layer, so \(N_{\text{params}} \approx 12Nd^2\) plus the embeddings. For GPT-2 small, \(12\times12\times768^2 = 84.9\) million in the layers, 38.6 million in the token table and 0.8 million in the position table, plus biases and normalisation parameters: 124.4 million, which is what the tracer and the published weights both give.

The arithmetic follows from the parameters. A matrix multiply costs two operations (a multiply and an add) per weight per token, so a forward pass costs about \(2N_{\text{params}}\) operations per token, plus the attention terms \(QK^\top\) and \(AV\), \(4NTd\) per token, which only dominate when \(T\) is several times \(d\). Training costs about three times the forward pass, the backward pass computing gradients with respect to both activations and weights: the widely used estimate of \(6N_{\text{params}}\) operations per training token (Jared Kaplan and colleagues, 2020).

Generating text, and the key–value cache

To generate, a decoder-only model runs on the prompt, samples a token from the last position’s distribution, appends it, and runs again. Done naively, step \(t\) recomputes all \(t\) positions. But with the causal mask, earlier positions never change when a token is added: their keys and values in every layer are the same as last time. So they are kept. The key–value cache stores \(K\) and \(V\) for every layer and position; each new step computes the query, key and value for the one new token, appends the key and value to the cache, and attends over it. The work per step falls from quadratic in \(t\) to linear.

The cache trades arithmetic for memory: \(2 \times N \times T \times d\) numbers per sequence. For GPT-2 small at 1,024 tokens in 16-bit numbers that is 36 MiB; for GPT-3 at 2,048 tokens, 9 GiB per sequence, which is why serving many users at once is limited by memory rather than arithmetic, and why so many of the changes in Part 3 shrink the cache. Generation therefore has two phases with different bottlenecks: prefill, processing the prompt in parallel, limited by arithmetic; and decode, one token at a time, limited by how fast the weights and the cache can be read from memory.

What it costs, and what came next

Attention’s strength is also its cost: every token compared with every other, \(O(T^2 d)\) arithmetic and, done directly, \(O(T^2)\) memory for the score matrix of each head in each layer. At 1,024 tokens this is small; at a million it is impossible. The other costs are the cache, the feed-forward layers that hold most of the parameters, and the number of sequential steps in generation. Nearly every architectural change since 2017 targets one of these, or the stability of training at scale; Part 3 goes through them. First, Part 2 opens up a trained model to see what all this machinery actually learns to do.

Terminology and where it comes from

Term Meaning here Origin
Attention Content-dependent weighted averaging over positions Bahdanau, Cho and Bengio’s 2014 translation model learned to “align and translate”, weighting source words for each target word; the word comes from cognitive psychology, where attention is the selection of some inputs over others.
Transformer The architecture Named by Vaswani and colleagues, 2017: the model transforms one sequence of vectors into another, layer by layer.
Query, key, value The three projections From databases and information retrieval: a query is matched against keys to retrieve values.
Head One of the parallel attentions The 2017 paper’s term (multi-head attention): each head is an independent reader of the sequence.
Residual connection Adding a layer’s input to its output He and colleagues’ 2015 ResNets, which learn the residual \(F(x) = H(x) - x\) rather than \(H(x)\).
Layer normalisation Per-token normalisation across features Ba, Kiros and Hinton, 2016, normalising over a layer’s units rather than over the batch as in batch normalisation (Ioffe and Szegedy, 2015).
Dropout Randomly zeroing activations in training Geoffrey Hinton’s group, 2012–14: units drop out of the network for a step.
Teacher forcing Training on the true previous tokens, not the model’s own outputs Ronald Williams and David Zipser, 1989, for recurrent networks: the teacher’s signal is forced in as input.
Logit An unnormalised log-score Joseph Berkson, 1944: the logistic counterpart of the probit.
BLEU Translation quality measure Bilingual Evaluation Understudy, Kishore Papineni and colleagues at IBM, 2002: an automatic stand-in (understudy) for human judges.
Encoder, decoder The stack that reads, the stack that writes Communication theory: encode a message into a signal, decode it at the other end.
