# Project Context: My Interactive Science Blog

- **Language Stack:** R (v4.4+) and Quarto (`.qmd`).
- **Data Visualization:** Prefer `ggplot2` or interactive `htmlwidgets` (like `plotly` or `dygraphs`) when embedding data plots.
- **Diagramming Standards:** System architectures and data relationship flows must be written using programmatic layout tools (like Mermaid blocks or custom ELKjs/Observable JS chunks) optimized for right-angle orthogonal line routing. Avoid line crossings.
- **Math:** Render all equations using valid LaTeX block (`$$`) or inline (`$`) configurations.
